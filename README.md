## 📖 About

**Butchery: Fabric** is an unofficial community port of the original Butchery mod, bringing it to the Fabric mod loader.

The project aims to preserve the original mod's experience while making it available to Fabric players. The port also introduces additional animal variants and associated content, alongside fixes for bugs discovered during development.

Created with permission from the original mod's creator, this project maintains credit and a link to the original work.

## ✨ Features

### 🐑 Additional Sheep Variants

More sheep colors, with the associated Butchery content to match:

- Multiple sheep color variants.
- Matching carcasses and heads.
- Corresponding head mounts.
- Variant-specific skins.

### 🌎 Biome-Specific Animal Variants

Additional biome-specific variants for several familiar animals, with corresponding carcasses and heads.

| Animal | Additional content |
|:---|:---|
| 🐄 **Cows** | Biome-specific variants, carcasses, and heads |
| 🐔 **Chickens** | Biome-specific variants, carcasses, and heads |
| 🐖 **Pigs** | Biome-specific variants, carcasses, and heads |

### 🛠️ Bug Fixes

- Fixed a bug where killing a Piglin with a cleaver incorrectly produced an Evoker carcass instead of a Piglin carcass.

More improvements and fixes may be introduced as development continues.

Two mods worth knowing about:

### 🔴 Fabric API — Required

[![Fabric API on Modrinth](https://img.shields.io/badge/GET%20FABRIC%20API-Modrinth-1BD96A?style=flat-square&logo=modrinth&logoColor=white)](https://modrinth.com/mod/fabric-api)

**Fabric API is a required dependency.** Install a version compatible with your Minecraft version before launching Butchery: Fabric.

Without the required Fabric API dependency, the mod may fail to load.

### 🔵 Just Enough Items (JEI) — Optional

[![JEI on Modrinth](https://img.shields.io/badge/GET%20JEI-Modrinth-1BD96A?style=flat-square&logo=modrinth&logoColor=white)](https://modrinth.com/mod/jei)

**JEI is entirely optional.** It provides an in-game graphical interface for browsing recipes and viewing ingredients, making it easier to discover how items are crafted without having to look everything up manually.

You do not need JEI simply to install the mod. Install it if you prefer a visual recipe guide.

> 💡 **Remember:** Fabric API is required; JEI is optional.

## ⚠️ Known Issues

This is an early beta, and some features still need work.

- 🪦 **Taxidermy:** An infinite head-mount bug is currently present.
- 🩸 **Blood fluid system:** Placing blood buckets can cause incorrect fluid behavior.

These issues have not yet been confirmed fixed. Please keep them in mind when testing the current development version.

## 📦 Supported Versions

| Minecraft version | Loader | Status |
|:---|:---|:---|
| **26.3** | Fabric | 🧪 Current target |
| **1.21.1** | Fabric | 🛠️ Planned, not yet released |

The current development target is Minecraft 26.3 with Fabric. A Minecraft 1.21.1 Fabric port is planned but is not available yet.

The aim is to maintain the latest stable Minecraft version selected for support, alongside Minecraft 1.21.1 when that port is ready. Other Minecraft versions and mod loaders are not currently planned.

Compatibility will be stated on each release once it becomes available. Do not assume that a build for one Minecraft version works on another.

## 🚀 Installation

**The public Modrinth release is not available yet.** Installation instructions for players will be finalized when the first release is published.

Once it is available:

1. Install Fabric Loader for a supported Minecraft version.
2. Download the matching Fabric API version.
3. Download the appropriate Butchery: Fabric release from Modrinth.
4. Place the mod JAR files in your Minecraft `mods` folder, or install them using a compatible launcher.
5. Optionally install JEI for graphical recipe browsing.
6. Launch Minecraft using your Fabric profile.

Check the release information for exact compatibility and any additional dependencies before launching.
