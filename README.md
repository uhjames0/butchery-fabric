## 📖 About

**Butchery: Fabric** is an unofficial community port of the original Butchery mod, bringing its gameplay and content to the Fabric mod loader.

The goal is to preserve the original experience while making it available to Fabric players. This port also introduces additional animal variants and associated content, alongside fixes for bugs discovered during development.

Created with permission from **jmods**, the original mod's creator, this project retains credit and a link to the original work.

## ✨ Features

### 🐑 Additional Sheep Variants

Additional sheep colors with matching Butchery content:

- Multiple sheep color variants.
- Matching carcasses and heads.
- Corresponding head mounts.
- Variant-specific skins.

### 🌎 Biome-Specific Animal Variants

Additional biome-specific variants for several familiar animals, with corresponding carcasses and heads.

| Animal | Additional content |
|:---|:---|
| 🐄 **Cows** | Biome-specific variants, carcasses, and heads |
| 🐔 **Chickens** | Biome-specific variants, carcasses, and heads |
| 🐖 **Pigs** | Biome-specific variants, carcasses, and heads |

### 🛠️ Bug Fixes

- Fixed a bug where killing a Piglin with a cleaver incorrectly produced an Evoker carcass instead of a Piglin carcass.

More improvements and fixes may be introduced as development continues.

### 🔴 Fabric API — Required

[![Get Fabric API](https://img.shields.io/badge/GET%20FABRIC%20API-Modrinth-1BD96A?style=flat-square&logo=modrinth&logoColor=white)](https://modrinth.com/mod/fabric-api)

**Fabric API is required.** Install a version compatible with your Minecraft version before launching Butchery: Fabric.

Without the correct Fabric API dependency, the mod may fail to load.

### 🔵 Just Enough Items (JEI) — Optional

[![Get JEI](https://img.shields.io/badge/GET%20JEI-Modrinth-1BD96A?style=flat-square&logo=modrinth&logoColor=white)](https://modrinth.com/mod/jei)

**JEI is optional.** It provides an in-game interface for browsing recipes and viewing ingredients, making it easier to discover crafting recipes.

You do not need JEI to run the mod. Install it if you prefer a visual recipe guide.

> 💡 **Remember:** Fabric API is required; JEI is optional.

## ⚠️ Known Issues

This is an early beta, and some features still need work.

- 🪦 **Taxidermy:** An infinite head-mount bug is currently present.
- 🩸 **Blood fluid system:** Placing blood buckets can cause incorrect fluid behavior.

These issues have not yet been confirmed fixed. Please keep them in mind when testing the current release.

## 🚀 Installation

Until the Modrinth submission is approved, download playable releases directly from GitHub.

### 📥 Download and Install

1. Open the [GitHub Releases page](https://github.com/uhjames0/butchery-fabric/releases).
2. Download the Butchery: Fabric JAR matching your Minecraft version.
3. Install Fabric Loader for that Minecraft version.
4. Download and install a compatible version of [Fabric API](https://modrinth.com/mod/fabric-api).
5. Place both JAR files in your Minecraft `mods` folder, or install them through a compatible launcher.
6. Optionally install [JEI](https://modrinth.com/mod/jei) for graphical recipe browsing.
7. Launch Minecraft using your Fabric profile.

Check the release notes for compatibility requirements and any additional instructions before launching the game.
