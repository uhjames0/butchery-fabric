## 🥩 About

Butchery is a Minecraft mod focused on immersive butchering. This project brings it to **Fabric**, with additional animal variants and fixes developed during the port.

This is an unofficial community port, created with permission from the original mod's creator.

## ✨ Features

### 🐑 Additional Sheep Variants
- Multiple sheep color variants.
- Matching carcasses and heads.
- Corresponding head mounts.
- Variant-specific skins.

### 🌍 Biome-Specific Animal Variants

Additional variants with corresponding carcasses and heads for:

- 🐄 Cows
- 🐔 Chickens
- 🐖 Pigs

### 🛠️ Bug Fixes
- Fixed a bug where killing a Piglin with a cleaver incorrectly produced an Evoker carcass instead of a Piglin carcass.

More fixes and improvements may be introduced in future releases.

## ⚠️ Known Issues

This is an early beta, so expect bugs.

- 🪦 **Taxidermy:** An infinite head-mount bug is present.
- 🩸 **Blood fluid system:** Placing blood buckets can cause incorrect fluid behavior.

These issues have not yet been confirmed fixed.

## 📦 Supported Versions

| Minecraft version | Mod loader | Status |
|---|---|---|
| **26.3** | Fabric | 🧪 Current target |
| **1.21.1** | Fabric | 🛠️ Planned — not yet released |

The goal is to maintain the latest stable Minecraft version selected for support, alongside Minecraft 1.21.1 when that port is ready.

Other Minecraft versions and mod loaders are not currently planned.

Compatibility and availability will be confirmed when releases are published.
